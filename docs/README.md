# OpenAgent Knowledge Base

OpenAgent is now an OpenAgent-owned GUI workspace for external opencode servers. The vendored opencode runtime, generated local SDK, TUI, server, and fork-maintenance workflow have been removed.

## Current Scope

- Desktop app and platform integrations
- Web GUI and project/session workflows supported by the pinned `@opencode-ai/sdk`
- Shared UI components
- Small GUI utility package

Runtime behavior, providers, agents, tools, storage, and server APIs are owned by external opencode.
