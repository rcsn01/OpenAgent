# OpenAgent VS Code Extension

This extension opens the `openagent` CLI beside your editor and can insert file references into the active session.

## Prerequisites

Build or install the `openagent` CLI before using the extension.

## Features

- Quick launch with `Cmd+Esc` or `Ctrl+Esc`
- Start a new side-by-side session with `Cmd+Shift+Esc` or `Ctrl+Shift+Esc`
- Insert file references with `Cmd+Option+K` or `Ctrl+Alt+K`

## Support

Report issues at https://github.com/rcsn01/OpenAgent/issues

## Development

1. Open `sdks/vscode` in VS Code.
2. Run `bun install` in that directory.
3. Press `F5` to launch the extension host.
